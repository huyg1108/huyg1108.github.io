description: >-
  A computer vision project that classifies fruit images into six categories: fresh apples, fresh bananas, fresh oranges, rotten apples, rotten bananas, and rotten oranges. The model was trained in Python using TensorFlow/Keras, with both a custom CNN and InceptionV3 transfer learning, then evaluated using accuracy, learning curves, and a confusion matrix.
